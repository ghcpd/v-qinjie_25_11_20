# Next.js Security Evaluation - Demo Project

This repository contains a minimal Next.js project demonstrating insecure and secure variations for UI security evaluation.

Run dev: npm run dev
Scan: npm run scan

Folders:
- insecure/ - initial vulnerable code
- secure/ - fixed secure code
- scripts/ - helper scripts
- reports/ - scan results and report

Use the batch scripts on Windows: scripts\setup.bat and scripts\run_security_tests.bat
